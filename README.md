# 全球潮汐 · 网页版

一个纯静态、无后端、可离线的潮汐预报与黄金钓鱼时间网站。打开即用，不需要 AppID、不需要微信开发者工具、不需要部署云函数。

对标「全球潮汐」类 App，提供：潮汐曲线与涨退潮时刻、逐小时天气与 16 天预报、风浪海洋数据、黄金钓鱼时间、月相与大小潮、站点搜索。

---

## 一、如何打开

方式一（最简单）：直接双击 `index.html`，用浏览器打开即可。

方式二（推荐，功能更稳定）：在项目目录启动一个本地静态服务器，然后访问 `http://localhost:8000`：

```bash
python -m http.server 8000
# 或
npx serve .
```

> 说明：直接双击也能用（代码按 `file://` 环境设计，全部为经典 `<script>` 标签，无 ES 模块、无打包工具）。但某些浏览器对 `file://` 下的跨域请求限制更严，若天气/风浪数据拉不到，请改用方式二。

## 二、部署到网上

整个文件夹是纯静态资源，可原样上传到任意静态托管，例如：

- GitHub Pages / Netlify / Vercel / Cloudflare Pages
- 任意对象存储 + CDN（OSS / COS / S3）

无构建步骤，无环境变量，无密钥。

## 三、功能一览

- **潮汐曲线**：24 小时潮位曲线，可拖动查询任意时刻的潮高与涨退潮状态，标注满潮/干潮极值与当前时刻。
- **涨退潮时刻**：当日每次满潮、干潮的时间、潮高与相邻潮差。
- **日期选择**：日期条（昨天/今天/明天…）+ 日历控件，可查看未来一年与过去一周（数据范围取决于估算模型）。
- **天气**：当前天气、逐小时预报（24h）、16 天中长期趋势。
- **风浪海洋**：浪高、浪向、浪周期、涌浪、海表水温、洋流，以及出海适宜度评级。
- **黄金钓鱼时间**：综合月相、潮汐动能、太阴时段、气压、风力、水温、晨昏，给出 0–100 鱼活跃度、最佳作钓时段、今日因子与 7 天鱼情日历。
- **鱼种与钓组教程**：按钓场类型筛选常见海钓鱼种，查看活跃季节、水层、位置、饵料和适配钓组，并提供浮漂、底钓、路亚与船钓钓组的图解组装步骤。
- **月相**：新月/满月/上下弦，月龄、照亮比例、月出月落月中天、大小潮判断。
- **位置选择**：优先使用浏览器实时定位并持续跟随；也可以打开地图，拖动准星选择任意坐标。
- **站点搜索**：支持按中文名、英文名、国家搜索；按港口/验潮站/岛屿/潜水点/沉船点/冲浪点分类；最近使用记录。
- **单位切换**：潮位（米/英尺）、风速（公里时/米秒/节/蒲福风级）、温度（摄氏/华氏）。
- **离线**：看过的站点潮汐调和常数、天气风浪数据都缓存到浏览器本地，断网时可复用。

## 四、数据来源与精度说明

| 数据 | 来源 | 说明 |
| --- | --- | --- |
| 潮汐（美国站点） | [NOAA CO-OPS](https://tidesandcurrents.noaa.gov/) 官方调和常数 | 权威，精度等同官方 |
| 潮汐（其他站点） | [Open-Meteo Marine](https://open-meteo.com/en/docs/marine-weather-api) 全球潮位序列 | 自动拟合调和常数，联网获取 |
| 潮汐兜底 | 本地天文估算模型（Schureman 调和法 + 纬度假定潮差） | 网络不可用时提供趋势参考 |
| 天气 / 风浪 | [Open-Meteo](https://open-meteo.com/)（免费、免密钥、CORS 友好） | 逐小时/逐日，联网获取 |

> 免责声明：系统会自动尝试 NOAA、Open-Meteo 全球潮位与本地估算模型，并标注当前生效来源。除官方数据外，任何估算或拟合潮位均不可用于航行安全、航道水深等涉水安全决策。黄金钓鱼时间为经验模型参考值，不构成渔获保证。实际出海请以现场海况与官方海事信息为准。

## 五、目录结构

```
global-tide-web/
├── index.html          应用外壳（四个视图 + 搜索 + 底部导航）
├── css/
│   └── style.css       深色海图设计系统
└── js/
    ├── astro.js        天文计算（日月位置、月相、日出日落、月中天）
    ├── tide.js         调和潮汐推算内核（Schureman）
    ├── fishing.js      黄金钓鱼时间算法
    ├── util.js         格式化 / 单位 / WMO 天气码 / 时区
    ├── draw.js         潮汐曲线与月相绘制（Canvas）
    ├── stations.js     全球点位数据集（约 100 个港口/岛屿/潜点）
    ├── store.js        本地存储（localStorage 缓存 + TTL）
    ├── data.js         数据层：直连公开接口 + 缓存 + 估算兜底
    └── app.js          应用控制器（页面渲染、交互、搜索、状态）
```

脚本按依赖顺序加载：`astro → tide → fishing → util → draw → stations → store → data → app`。

## 六、本地二次开发

- 修改点位数据：编辑 `js/stations.js` 中的 `RAW` 数组（字段：`id/name/nameEn/country/cc/lat/lon/tz/dst?/type/noaa?`）。
- 给美国站点加权威潮汐：在站点对象上补 `noaa: '<验潮站编号>'`。
- 调整鱼情权重：编辑 `js/fishing.js` 里的 `WEIGHTS`。
- 调整配色：编辑 `css/style.css` 顶部的 CSS 变量（`--abyss`、`--tide` 等）。

无需安装依赖，无需编译。
